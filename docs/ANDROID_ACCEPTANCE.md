# Android 0.5.0 验收

1. 打开「助手 → 对话」，问“今天出门要带伞吗”，观察天气工具记录和回答。联网失败应保留已有任务和配置。
2. 发送“十分钟后提醒我喝水”：确认前清单不能变化；点确认后在工作台出现，连接状态显示局部同步。点完成后清单与实屏文字消失，天气/行情/固定红色保留。
3. 发送“记住：我下雨时会带伞”，在卡片确认后，到「我的 → 偏好记忆」查看、编辑、停用、删除、恢复。
4. 在「我的 → 本地提醒」开启本地提醒，允许系统通知；检查精确闹钟状态。设置一项两分钟后到期的待办验证通知，再验证完成后不再通知。免打扰时提醒会顺延，省电设置可能影响到达时间。
5. 提出一个新增操作后先取消卡片；清单不得变化。已有卡片对应事项被手动改动后再确认，应拒绝旧卡片。
6. 助手请求中点击停止，稍候不得出现迟来的写操作。断开网络时应能继续手动编辑，联网后按既有同步策略处理。
7. 普通待办操作保持综合布局与分区局刷；只有明确确认布局卡片或点击应用布局才全刷一次。

自动验证：33项原生助手检查、原有原生布局/同步检查、Mac/C++/网页回归、15项Python测试通过；真实 DeepSeek 只读工具调用通过。通知真实到达和屏幕光学效果仍需以上人工验收。


界面验收：

- 只显示工作台、助手、我的三个主入口；从助手更多菜单进入设置后，返回应回到助手。
- 新增入口在工作台底部。点击圆圈完成后可撤销；点击正文编辑；删除放在更多菜单中且需确认。
- 助手长对话滚动时输入框仍在底部。输入未发送的文字时等待一分钟，设备更新不能清掉草稿或主动收起键盘。
- 在「我的 → 屏幕布局」选择卡片后取消应用，当前配置不得变化；确认后才执行一次全刷。
- 在系统调大字体，检查待办长标题换行、表单标签、按钮和底部导航；输入法弹出后发送按钮仍可触达。


场景与卡片验收：

1. 「我的 → 选择场景」浏览三套真实预览；取消确认时屏幕和保存配置不改变。选择工作桌面确认应用，应全刷一次且保留清单。
2. 在搭配卡片中选择盆栽与周进度；完成/撤销待办后本机数字对应增减，达到阶段时叶片变化，天气/行情/固定红色保留。
3. 添加一个明天的重要日期，选倒计时卡；移除后应擦掉旧字。更换小纸条或状态，同样不能残留旧内容。
4. 工作台进入专注，开始5分钟、暂停/继续、允许系统通知后锁屏等待。验证通知仅一次；屏幕返回前台后显示真实剩余分钟。停止后不得再提醒。
5. 生活画报应显示大日期、农历、月历、季节山景及已核验的节气；日常更新无需反复切场景。
6. 未启用共享时分别统计本机历史；启用后按任务ID合并，不将两个数字直接相加。Mac接管仍需明确应用，不能覆盖手机当前画面。

第三轮（0.6.0）补充验收：

1. 「我的 → 习惯打卡」添加/打卡/撤销，选择习惯卡；跨北京时间午夜后当天勾选清空，历史保留。
2. 手机日历只申请读取权限，勾选所需日历；取消授权或停用时不泄露旧日程。确认下一场未结束日程与系统一致。
3. 通勤页填写本人高德Web服务Key与明确起终点，点击查询；失败保留有效缓存，15分钟后显示过期。助手读取建议时不得把过期缓存说成实时路况。
4. 收藏一个组合，导出JSON检查不含任务、地址或密钥；导入后取消预览不应改变设备，应用需明确全刷。
5. 按ROUND3说明启动隔离共享服务，两台客户端同步同一个完成ID应只计一次；另一端撤销后重放旧记录不得复活。
6. 自动共享开关默认关闭，开启后仅在安卓前台执行；输入框编辑时不打断。配置不同服务器必须重新填写相应凭据。
7. 使用invite凭据仅能投递留言；owner查看后选择显示/忽略，未接受前屏幕不变。模板和插件发布只到自己配置的服务，不是公开商城。
