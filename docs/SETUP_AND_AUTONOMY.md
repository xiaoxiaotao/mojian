# 首次配置、设备自主更新与重复待办

Android 0.7.0 / Mac 0.4.0。

## 第一次使用

手机「我的 → 首次配置向导」，Mac侧栏「首次配置」。全新客户端没有设备地址时自动进入；已有用户可主动打开，不会自动覆盖现有屏幕。

1. 开启蓝牙，在工作台附近发现设备。已经知道地址的用户仍可手动连接。
2. 设备支持2.4GHz Wi-Fi。未配置过网络的设备开机提供五分钟配网窗口；已有网络的设备请在开机完成后按住BOOT键两秒，再发送新网络。不要按住BOOT再重启，否则板卡可能进入下载模式。
3. 在客户端填写Wi-Fi名称与密码，允许系统蓝牙配对。配置经加密BLE特征分包发送，应用不把密码写入草稿、配置文件、模型上下文或日志。设备连通后才将网络配置作为单条NVS记录保存；30秒未连上则退回原网络。开放Wi-Fi可留空密码。BLE只完成发现和配网，日常内容通过同一局域网HTTP同步，无访问口令。
4. 选择工作、专注或生活桌面。明确应用时全刷一次，保留已有清单；已经建立基准且不换布局时，可继续使用原桌面。
5. 按需启用自主更新，添加第一条待办，完成向导。日历/通知权限和DeepSeek、高德配置不作为基础使用的强制门槛。

蓝牙配对需要用户在系统窗口确认，固件升级后若旧配对失效，请在系统蓝牙设置移除旧配对，再重新配对。蓝牙配网不是BLE传整幅图片，也不依赖Mac服务。

## 手机和Mac退出后

手机「我的 → 自主更新」，Mac「首次配置 → 第四步」可管理设备自主运行。开启是明确操作，不自动给老用户改变显示行为。

- **时钟**：ESP32使用NTP校时（网络可用时）及客户端提供的有效时间，按分钟更新。只改时钟窗口，不显示秒针。
- **天气**：ESP32每10分钟直接请求Open-Meteo当前温度和天气代码，校验HTTPS证书和原始主机名；遇到保留地址/Fake-IP或连接失败时，仅天气请求使用独立公共DNS解析兜底（223.5.5.5 / 119.29.29.29），不修改全局DNS、不关闭证书校验。失败两分钟后重试，保留上次有效缓存，超过一小时显示“旧天气”。页面显示更新时间，不能把缓存当作实时天气。
- **布局**：工作布局及手机生活画报使用左上时钟/右上天气；Mac万年历使用右上时钟/左下天气。设备天气是简洁城市、天气、温度和更新时间排版，与客户端预览字体不完全相同。其他待办、股票、卡片、固定红色保留。
- **稳定性**：天气请求在独立任务中执行，显示和HTTP服务仍在主循环。BLE连接中暂停启动自主刷新；天气TLS请求期间暂让出蓝牙内存，结束后恢复广播。仅像素实际变化时局刷，不因检查周期或天气请求自动全刷。
- **存储**：自主开关、城市字形、坐标和有效天气缓存独立保存；不每分钟将整幅画面写入Flash。

这是**持续供电时**的独立时钟/天气更新。断电重启后纸面会保留，但控制器基准需用户明确应用一次布局；不会为恢复基准偷偷全刷。没有网络且未获得有效时间时，不伪造当前时间。

本轮设备**尚不自主抓取股票、系统日历或刷新全部卡片/月历**；它们继续由客户端提供。自主天气不是自动场景轮播、也不是云服务。

接口：`GET/POST /api/local/autonomy`，POST包括enabled、latitude、longitude、128×20单色城市图（320字节base64）。坐标/图像/长度严格校验。设备状态声明autonomy_supported、provision_supported、provision_open和metadata_limit。

## 重复待办

两端新建/编辑时可选：不重复、每天、周一至周五、每周、每月。必须设置截止时间。周一至周五不承诺法定节假日/调休识别。

- 完成当前事项后，当前项进入本机处理记录，从活跃清单移除，仅生成一条未来事项。
- “跳过本次”同样推进到下一次，但不计入完成量。安卓在事项更多菜单，Mac在事项右键菜单。
- 延迟多天才处理，不生成一长串积压任务；直接找到截止时间之后、且晚于当前时间的下一次。
- 每月保留原始日号：1月31日 → 2月28/29日 → 3月31日；不永久漂移到28日。只修改时刻不会丢失31日锚点。
- 下一次ID按series+上海自然日生成，两端对同一次处理得到相同ID。重复元数据随设备活跃事项同步，跨端读取不会丢规则。
- 撤销完成/跳过会先检查下一次尚未处理、内容未改，随后移除这条下一次并恢复原项。下一次被改名、改期或已处理时拒绝直接撤销，不擦除另一端的新工作。
- 删除活跃重复事项终止该系列的继续推进；可在本机记录中恢复。无客户端操作时，设备不会自行把待办标为完成。

当前是“处理后推进”的重复待办，不是每天自动堆叠未完成任务；完成文字历史仍按既有本机规则保存，共享服务交换去重统计，不等于完整历史备份。

## 开发与升级

- 固件新增wifi_provision、provision_frames、autonomy、autonomy_geometry。加密特征UUID以0004结尾；20字节包，S开始/C继续/E结束，最大256字节，非法序列/空字节拒绝，断开后清空。
- HTTP画面元数据上限提高至8192字节，以容纳重复规则；安卓优先读取设备声明，旧设备继续按4096限制。
- 自主字体仅含固定天气用字，来自Noto Sans CJK，OFL及来源保留；城市文字由客户端生成小位图，无需在ESP32放完整中文字库。ISRG X1/X2为公开信任锚，来源见THIRD_PARTY_NOTICES。
- 固件超过原1.25MiB应用槽，采用单应用2.5MiB分区。**NVS、otadata、LittleFS和coredump起始地址及容量保持原值**，保留现有清单、帧与网络配置。当前升级入口为USB；不声明支持双槽OTA。未来改变分区仍须另行做迁移/备份，不能直接套用min_spiffs擦掉原文件区。
- 本轮未改屏幕波形、寄存器极性或扫描模式。仍须区分软件回读/区域验证与实屏光学验收。
