# 历史记录查找

适用 Mac 0.4.6 / Android 0.7.6。

Mac：工作台 → 查找历史记录；安卓：工作台 → 事项处理记录。

输入事项标题中的文字，配合类型筛选。Mac区分已完成、已跳过；安卓另有已删除，保留最近最多100条，每次显示20条，可继续展开。Mac只查找仍保留在本机任务列表中的完成/跳过记录；删除的Mac事项没有新增回收站。已裁剪或其他客户端尚未同步来的记录无法凭搜索找回。

搜索忽略首尾空白及英文大小写；同一事项只展示最新保留记录。Android搜索最多100字，返回页面保留本次查询；Mac关闭窗口后重置。查询不进入偏好存储或模型。

点击恢复，确认后才加入待办。确认时重新核验记录是否变化，沿用原截止时间，可能仍逾期。清单满八项时拒绝；重复事项只有下一次仍未修改且未处理时才可撤销。继续使用已有的同步和黑白局刷规则，不自动切换布局。

浏览、搜索、筛选均只读本机，不调用模型、不写设备、不改完成统计。恢复属于明确操作；设备离线时遵循原有离线同步机制。各端历史文字尚未完整双向同步。
