# 场景与卡片：Android 0.5.0 / Mac 0.2.6

## 使用

手机进入「我的 → 选择场景」，可预览工作桌面、专注桌面、生活画报，点击图片查看大图。应用场景会明确确认并全刷一次。日常任务与卡片更新使用原有分区局刷，不自动轮播。

「搭配卡片」管理工作排版的两个右侧槽位；支持盆栽、真实周进度、重要日倒计时、出门提示、状态与小纸条。进阶排版继续保留六套预设及自定义比例；专注、极简、自定义与生活画报各自保留结构，卡片不会任意挤入它们的专用区域。

手机重要日期最多6个；Mac保留原有12个日期。两端的日期配置与完成历史未做云端自动合并，不能简单相加。盆栽与周进度按当前控制端的本机记录计算。Android统计记录与可恢复历史分开保存，撤销时通过活跃任务ID剔除完成记录。

工作台「专注一小会儿」支持5至90分钟、关联事项、开始/暂停/继续/结束；专注场景显示剩余分钟。手机退出后由系统闹钟处理完成通知，通知权限/精确闹钟/厂商省电影响到达。屏幕分钟变化仍依赖前台连接；重新打开按保存的截止时间校正。不会宣称后台持续五秒刷新。

生活画报为本地历法与程序绘制山景：公历、农历、月历、2026已核验节气、季节标题和重要日期。无需AI Key或生图服务，不提供未经核实的黄历宜忌或其他年份节气日期。

Mac「信息卡片」加入同名场景入口和盆栽/状态选择；按场景按钮明确全刷，普通信息变化延续原来的黑白局刷。手动场景选择遵循原有作息覆盖到下个边界的规则。

## 实现

Android新增ScreenData（确定性统计/日期/计时/场景配置）、ScreenPanel（原生设置与同源预览）、ScreenSync（视觉回执与控制权）、FocusAlarm（系统到期通知）。DeskRenderer.cardsPatch按已知布局裁剪清底，不跨越y=80..103固定红色带。metadata仍受4KB限制，不把完整完成历史发送给ESP32。

screenPending独立于任务dirty。发送期间新的设置修改会使旧版本回执失效；相同任务不代表设置已成功同步。并发配置变化停止自动覆盖；丢失视觉回执可通过设备phone_settings识别。场景失败后普通同步使用当前设备配置，不用待应用的新场景覆盖原内容。旧版本cardsVersion=0保持原样，明确保存卡片或应用场景后进入版本1。

固件、扫描模式和底层波形未改动。固定红色仍由既有固件维护，实际画面不以程序回执代替光学确认。
