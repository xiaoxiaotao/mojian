## 为什么不直接加延时或调电压

当前参考波形为固定寄存器表。BUSY等待函数的超时参数规定最多等待多久，实际有BUSY引脚时等待由其状态结束；它不是波形时长。刷新后额外sleep也不会自动拉长已经输出的驱动脉冲。延长驱动需要匹配的波形/时序依据，不能把延长软件等待当成低温补偿。

外部校正LUT分支写入VCOM 0x30，是锁定上游同型号实现；没有本面板批次资料和测量前，不修改此值，也不将通用三色OTP的说明误套为本寄存器分支绝对可调或绝对不可调。

## 新增隔离验证

`tests/reference_ram_model.h`解码实际SPI命令/数据，重建窗口及0x10/0x13两组RAM；在每次0x12时核对旧画面与前次逻辑画面、新画面与目标，并核对刷新后previous同步。通过实际localPaint和原参考驱动执行12轮多窗口、移动内容、擦成空白、页边界及休眠唤醒，不向实屏写测试图案。该模型不模拟颜料、电压、温度和真实SPI信号质量。

## 后续验证顺序

1. 保持修复版、相同布局和自然更新节奏。记录全刷后的干净起点及再次出现的时间/照片，分别关注旧黑字、框线和红色色带；不为掩盖症状而自动全刷。
2. 若复现，核实面板附近室温、DESPI-C02实际型号/RESE档位和接线；电压检查需要物理测量，不能从Wi-Fi RSSI或BUSY推断升压正常。调整硬件前保留现场。
3. 硬件条件核实后，再做单因素对照：先比较同型号原生全刷至局刷生命周期，或独立降低SPI频率排查信号问题。一次只改变一个条件，保留当前布局、红带和任务。全刷温度块可先用 `esp32-l-gx-full-temp-ab` 做候选对照（见[全刷寄存器对照实验](DISPLAY_FULL_REFRESH_AB.md)）；`0x50` 涉及红色极性，暂不单独改。该实验默认关闭且尚未实机验证。
4. 若需温度补偿或进一步改变LUT，应取得厂家针对面板/FPC批次的匹配资料。没有依据不直接套其他型号波形，不将更换ESP32-S3视为显示质量修复。

## 2026-11-10 厂家刷新资料核对

资料来源：
- [电子纸屏全刷、局刷、快刷有什么区别？](https://www.good-display.cn/news/105.html)
- [UC系列电子墨水屏局部全刷简介](https://www.good-display.cn/news/107.html)

关键结论：

1. 全刷支持单色、三色、四色，光学效果最好；**局刷只支持单色**，红色不能参与局刷；快刷支持多色但仍有残影。
2. 厂家明确建议：**每 5–6 次局刷/快刷后做一次全刷**，否则旧图像会断续、隐约显现；全刷可完全消除残影。
3. UC 系列还提供**局部全刷**模式：只对局部区域用全刷波形清残影，不需要整屏闪屏；厂家建议约 5 次局刷清一次。
4. 本机在两次全刷之间累计了 1000+ 次小窗口局刷（时钟/天气/内容），远超厂家建议；红色又只能全刷，因此固定红带出现暗红残留是符合厂家描述的累积残影，不是 A/B 构图或当前红色数据造成的。

对项目的含义：

- 继续把红色放在固定带、只在全刷写入，就必须接受周期性全刷或局部全刷清残影；否则红带会累积。
- 自动全刷不是“掩盖”，而是厂家推荐的维护动作；但频率应按**内容局刷次数**或时间控制，不能按时钟每分钟一次全刷。
- 最理想的是向厂家确认 UC8179 是否支持“局部全刷”及对应 LUT/命令，只清 `y=80…103` 带，不整屏闪。
- 在拿到局部全刷资料前，可选：可配置的维护全刷（默认关闭/用户显式开启）、出现残影时手动全刷、或彻底去掉红色。
