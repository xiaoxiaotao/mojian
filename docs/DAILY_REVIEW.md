# 每日收尾

Mac 0.4.3：工作台「每日收尾」。Android 0.7.3：工作台「每日收尾」，可点击「重新整理本机记录」。无需联网、设备或模型Key。

以北京时间自然日和整理时刻为准：

- 今日完成记录：本机仍保留、完成时间在今日零点至当前时刻之间的记录。跳过、删除、已撤销和未来时间的完成记录不计入。
- 已逾期：未完成、截止时间早于当前时刻。
- 今天稍后：未完成、截止时间从当前时刻到明日零点之前。
- 明日到期：明日零点至后日零点之前。
- 未设截止：仍未设置截止时间的未完成任务。
- 更晚安排：后日零点起的任务。

同一事项ID去重，分组互斥。重复事项使用现有实际实例，不推测未生成的以后实例。Mac随已有时钟更新；Android显示本次整理时间，可手动重新整理。待同步时会提示本机与屏幕可能不同。

页面只读，不改期、不完成、不通知、不调用模型、不写屏、不切下班模式。可明确点击复制摘要到本机剪贴板；不会自动发送给任何人。摘要含任务文字，分享由用户自行决定。

此页是保留记录的回顾，不是完整统计报表。Android处理历史有长度上限，已删除或尚未同步到本机的记录可能缺失；不将共享累计完成量与历史清单简单相加。显示没有记录不代表用户今天没完成工作。
