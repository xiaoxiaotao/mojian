# 测试与兼容性

当前版本 0.2.5，开发验证阶段。已验证 Apple Silicon、macOS SDK 15.2、ESP32-WROOM-32D、DESPI-C02 和 GDEY075Z08 800×480 面板。

## 自动化测试

运行 `sh tools/test.sh`：四组 Mac 隔离测试与四组 C++ 协议测试。Python 兼容服务另运行 `python3 -m unittest discover -s tests -v`（需安装 requirements.txt）。

覆盖作息、画面打包、Agent 提案、连接恢复、队列合并、手机模式保护、信息卡片、待办编辑和通知去重。测试无需真实 Key，不写真实屏幕。

源码独立导出的固件已编译通过。当前固件程序分区接近容量上限，新增功能需留意体积。

## 仍需社区验证

- 系统通知授权、专注模式、真实睡眠唤醒。
- EventKit 授权后的重复事件、时区与长期同步。
- 面板批次、温度、长期局刷残影与断电恢复。
- 正式签名、公证、安装升级与跨 Mac 迁移。
- Android 与 Mac 功能差异及更多硬件兼容。

模拟测试及设备回执不能替代实屏观察。修改波形需要注明面板型号、温度、现象与观察结果，并保留协议测试。
