# 墨间产品优化进度

## 已实现：0.2.5 待办编辑与提醒

- 修改未完成待办标题/截止时间，保留ID与置顶；编辑取消不保存。
- 最近一次完成可撤销，历史完成仍可恢复；恢复执行8条与3条置顶上限。
- 提前10分钟与到期分别检查，错过后24小时内补提醒；成功提交记录跨重启去重。应用运行且系统通知获准时生效。
- 通知失败可重试，改期按新截止时间判断；完成后清理对应通知。

## 已实现：0.2.4 信息卡片

- 重要日自然日倒计时、最多三项待办置顶、本周完成与目标。
- 用户主动授权并选择的系统日历下一事项；无需公开日历链接。
- 苏州逐小时降雨概率、体感与风速提示。
- Mac信息卡片配置页及黑白局刷显示；当前先展示本周进度与出门天气。
- 日历真实权限/事件读取需用户在系统窗口授权后验证；无自动授权。

## 已实现：0.2.3 连接、同步与操作反馈

- 网络中断后5、10、20、40、60秒退避重连；重新连接不自动导入旧待办。
- 本地保存与设备同步状态分开；显示待同步、正在局刷、失败原因和重试按钮。
- 只重试黑白局刷；手机布局、设备重启或布局不匹配要求明确应用布局，禁止静默全刷。
- 内容相同但任务元数据改变时仍同步；画面和元数据均相同才省略请求。
- Agent显示当前工具步骤，提供停止按钮和宿主120秒超时；停止/超时后旧进程结果不能进入新请求。
- 缺少模型Key时在对话内明确提示，不丢失用户提交的文字。

## 后续优先项

1. 待办手动排序、重复任务；改名、改期与完成撤销已完成。
2. 实际睡眠唤醒/系统通知联调、行情休市/过期提示；补提醒逻辑已完成。
3. 首次使用向导与设备配网、设备独立凭据。
4. 清单/设置导出与恢复，密钥保持钥匙串独立处理。
5. 正式签名与升级、固件容量优化、分发授权检查。
6. 连续多天断网/唤醒/高频编辑的真实设备试用。

本轮不改变屏幕波形，不增加新的全刷时机。协议回执不等同于光学效果验证。
