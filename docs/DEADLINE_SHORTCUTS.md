# 截止时间快捷选项

Mac 0.4.5 / Android 0.7.5：新增、编辑待办可使用「1小时后」「明天9点」「不设截止」。Mac工作台新增区也提供快捷按钮。

- 1小时后：从点击时刻增加3600秒，可能跨日。
- 明天9点：按北京时间的下一个自然日上午09:00，包括周末；不是下一个工作日。
- 不设截止：清除截止时间，并在当前编辑草稿中关闭重复，避免保存无截止的重复事项。
- 手动选择仍可用。Android修改任务时以原截止时间打开选择器；未设或无效时从当前北京时间开始。Mac日期控件也固定北京时间，避免系统时区不一致。

所有快捷操作仅修改表单草稿，按保存才进入原有编辑、新增和局刷队列；取消不修改事项。不自动完成、不新增系统提醒、不改变置顶或布局。重复事项的跨日修改继续使用原有月份锚点规则，不另造未来实例。
