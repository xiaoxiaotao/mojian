# 快速收集

Mac 0.4.4：工作台「批量收集」。Android 0.7.4：工作台「快速收集」，或其他应用通过系统分享选择墨间；支持纯文字的系统文字处理菜单（是否显示由来源应用/系统决定）。

## 操作

1. 手动粘贴多行文字，或主动分享纯文字到墨间。
2. 每行一件事；可先编辑。空行、同批重复标题及当前清单已有的同名标题被忽略。可去除行首`- `或`• `项目符号。
3. 查看预览后点击「确认加入待办」。确认时重新校验最新清单和容量，不沿用过时的预览。

一次输入最多4096个UTF-16字符，每条最多80个UTF-16字符，两端都遵守最多8条未完成。超长或容量不足时整批拒绝，不部分写入、不悄悄截断分享内容。不把“明天交报告”解释成日期，也不执行文字里的指令；截止时间和重复规则可随后单独设置。

确认后使用现有本地保存和同步队列，离线会待同步；普通同步仍黑白局刷，不自动切换布局。重复标题去重仅针对当前活跃清单，不使用已完成历史阻止同名新任务。

## 草稿和隐私

- 分享仅接受`text/plain`，不读取附件、图片、来源应用数据库或网址内容，不申请新敏感权限。分享/选中文字只是打开确认页，不立即创建事项。
- 不自动读取剪贴板。Mac仅点击「从剪贴板粘贴」才读取；安卓由用户通过系统粘贴操作输入。
- 未确认草稿不发给模型、不发送屏幕、不写业务偏好。安卓在配置重建时通过实例状态恢复，尚未实现长期草稿存储；强制停止/系统清除状态可能丢失。Mac取消关闭后放弃输入。
- 安卓有未处理草稿时，新分享不覆盖旧草稿，会提示先处理后重新分享；当前编辑/冲突/操作进行中时等待结束再打开收集页。复用现有Activity，避免两个独立界面同时持有旧清单。
- 点击确认才加入用户待办；后续助手访问仍遵循原有授权与确认边界。

当前验证包含纯文字Intent/选中文字载荷解析、类型和长度拒绝、重复/空行、名额限制、原子拒绝和界面布局。不同来源应用的系统分享面板、输入法与后台唤醒需要继续真机交互验收，不将载荷解析测试当作所有来源应用均已适配。
