# 第三轮：日常功能、跨端记录与共享扩展

版本：Android 0.6.0 / Mac 0.3.0。竞品的前期调研继续保存在本地忽略目录；本文件说明可公开的功能、使用方式与限制。

## 日常功能

安卓入口在「我的 → 日常与扩展」；Mac 在「日常与扩展」，卡片选择仍在「信息卡片」。

- **手机日历**：显式申请 READ_CALENDAR，只读用户勾选的可见日历。选未来七天内下一场尚未结束、未拒绝的日程；支持全天日程。前台每分钟检查，编辑输入时不打断；停用可清除显示数据。日历不发送给模型，无写日历权限。
- **安卓通勤**：手机配置高德 Web 服务 Key、具体起终点、到达时间和预留分钟。点击查询后向高德地理编码/驾车路线接口请求，显示耗时和建议出发时间。无法唯一解析的地址要求补充；失败保留原数据，15分钟后标过期。地址不放入模板或ESP32元数据，Key单独用Keystore加密。Mac沿用已有路线、交通和提醒功能。当前安卓为手动查询，不宣称后台实时交通提醒。
- **习惯打卡**：最多三个，每天手动完成/撤销，按北京时间换日，保留最多56天。可选右侧卡片。默认不触发系统通知，不模拟传感器数据。
- **每日灵感**：内置七条原创短句，按日期确定，无需模型调用。
- **重要日期**：两端最多12个，按自然日倒计时。ESP32只接收当前倒计时文本，不携带完整收藏、日历来源和打卡历史。

普通卡片变化保持黑白分区局刷，固定红色带y=80..103保持白平面隔离；场景和几何排版切换仍需明确应用全刷。

## 场景收藏与模板

两端可保存最多12个组合。安卓使用系统文件选择器导入/导出JSON；Mac使用原生文件面板。应用前预览，明确确认全刷。导入只接受支持的布局、比例、卡片和长度范围，不运行脚本。

`mojian-template-v1`仅包含名字及视觉配置：layout、ratio、scene、cardsVersion、card1/card2、weeklyGoal、note、deskStatus/statusNote。小纸条文字属于分享内容，请在发布前检查。任务、地址、设备IP、API Key、日历来源、完成历史和习惯记录不属于模板。

示例：[轻办公](../examples/community/work-template.json)。不需要云端也可以用文件分享。

## 跨端待办与控制权

ESP32的活跃清单是共同的设备状态；新增Mac基于已知基准、本机修改与设备最新清单的三方合并。不同事项的增删可合并；同一事项双端冲突或合并后超过8条时停止并提示核对，不能偷偷覆盖。Mac保存独立基准文件，完成历史与活跃事项不混同，远端恢复的事项不同时残留重复完成ID。未确认的首次不同清单仍要求用户明确读取来源。

Mac每5秒检查设备变化，普通更新不全刷。手机`.phone`布局仍受原有控制权保护，Mac必须明确应用才接管，不能以新增功能为由自动切布局。

新版提交携带`expected_content_key`，固件在保存/绘制前比较当前版本，不一致返回409、不落盘、不刷新；预条件不是永久元数据。兼容旧客户端仍可提交，只有新版客户端携带预条件的请求具备这项并发保护。

## 可选共享服务

`server/community.py`为单个桌面/家庭组的自托管服务，不是已经上线的公共云。Python 3.11+，仅标准库；SQLite持久化，不要求模型密钥。

```sh
python3 server/community.py --data data/community --port 8788
```

默认只监听127.0.0.1。需要同网手机访问时，由部署者明确改为局域网监听地址或`--host 0.0.0.0`；公网须配置域名、TLS反向代理及运维备份。手机/Mac拒绝公网明文HTTP，局域网调试HTTP允许。部署文件与凭据须留在忽略的data目录，不提交Git。

首次启动将两种随机凭据写入`data/community/credentials.json`（600权限、目录700），不输出凭据：

- `owner`：在本人客户端「共享与扩展/可选共享服务」配置，可读写共同记录、模板、插件和收件箱。
- `invite`：仅允许提交待审留言，不能读取任务记录、模板、插件或收件箱。按需交给留言者，不要分享owner凭据。

凭据由手机Keystore/Mac钥匙串保存；修改服务地址时需重新填写该服务凭据。此授权仅针对可选远程服务，ESP32同网直连仍无需访问口令。

### 共同记录

点击「同步记录」交换完成记录、习惯和重要日期；默认**显式同步**，也可自行开启每分钟自动共享：Mac须应用运行，安卓仅前台；不宣称安卓退出后仍在云端后台同步。完成量以任务ID去重，撤销是带时间戳的墓碑，不能简单把两台设备的数字相加。习惯每天的勾选/撤销也有时间戳，重放旧记录不能恢复新撤销；日期和习惯移除同样有墓碑。同时间戳用规范化JSON确定顺序；依赖客户端正常系统时间，未来超过5分钟的时间戳被拒绝。没有同步过的本机统计仍标为本机。

服务限制共同习惯最多3个有效记录、32个含墓碑记录；完成记录4096条，有效日期12条、含墓碑128条。到达容量返回错误保留原数据，当前尚无自动归档界面。共享数据不是跨端任务文字历史备份；活跃清单仍从ESP32同步。

### 留言

访问共享服务根页面可使用邀请凭据填写署名/留言。凭据只放Authorization请求头，不放网址和浏览器持久存储。每小时最多30条，100字以内。本人在客户端收件箱选择显示/忽略；显示只替换小纸条卡，不自动创建任务、调用模型或整屏轮播。接受表示已选择该内容，实际屏幕同步状态仍按原有同步队列显示，连接失败不会冒充已显示。

### 模板库与开放数据卡片

本人可将当前排版发布到自己的服务，并从两端读取模板库。不是内置联网商城，没有公开发布账号体系或付费功能。

数据卡片使用`mojian-card-v1`，支持`text`（静态文字）、`countdown`（自然日倒计时）、`daily`（每日短句）。不执行JavaScript/Python，不访问任意插件网络地址。第三方开发者可提供该JSON，自托管管理员审核后发布。安卓可从JSON文件发布，Mac可读取/使用；两端都可用命令行工具发布：

```sh
python3 tools/community_publish.py templates examples/community/work-template.json
python3 tools/community_publish.py plugins examples/community/daily-question.json
python3 tools/community_publish.py plugins examples/community/team-note.json
```

接口：`GET/POST /v1/state`、`GET/POST /v1/templates`、`GET/POST /v1/plugins`、`GET/POST /v1/messages`、`PUT /v1/messages/{id}`。需Bearer授权，不使用cookie，不自动跟随重定向。

## 验证与未部署部分

- Python共享服务隔离HTTP测试：授权角色、留言审核、完成去重/撤销/重放、习惯合并/撤销/移除、模板隐私、插件脚本拒绝、异常数据不改变状态、重启持久化。
- Mac新增ExtensionTest：三方合并、删除不复活、同项冲突、模板隐私、远程传输策略、数据插件、习惯与共享撤销重放。
- 安卓ExtensionChecks及原有ScreenChecks/DeskChecks/AssistantChecks/UiChecks：使用隔离数据，不向用户设备注入测试任务。
- 不把API回读等同于光学效果验收。日历系统权限、高德实际Key额度、前台日历更新和公网TLS部署，分别需要用户授权/有效服务配置及场景验收。
- 本轮不启用公共云、不公开设备、不搭建付费模板市场，不做动画/秒级刷新或未经核验的新闻源。未来可在已有数据插件协议上扩展经审核的数据提供者。
