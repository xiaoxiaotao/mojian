# 连接与数据状态

Mac 0.4.2：左侧「连接与数据」，或侧栏底部状态入口。Android 0.7.2：「我的 → 连接与数据状态」，也可点击页首连接状态。

## 状态的含义

- **设备可访问**：当前地址在最近20秒内返回过响应。这不等于当前所有内容已上屏；旧响应或更换地址后显示待确认。
- **同步回执**：单独显示待同步、冲突/核对、需要应用布局、其他客户端控制或最近发送回执。本次尚无回执会明确标注；更换设备地址不沿用旧设备回执。
- **天气缓存**：客户端缓存超过1小时标记过期。最近更新失败时保留已有缓存，并标明失败和缓存状态；明显超前的时间戳不当作新数据。
- **行情缓存**：显示已配置股票的缓存覆盖数量；供应商行情时间不等于本机获取时间，可能延迟或休市，不承诺实时行情。
- **通勤缓存**：超过15分钟标记过期。初次使用需高德Web服务Key、起终点；更新失败不编造耗时。

「只检查连接」仅请求设备状态，不导入待办、不接管布局、不提交画面或全刷。配置按钮跳到实际设置页；获取天气/行情只更新客户端缓存，上屏继续遵循原同步流程。打开诊断页本身不触发额外查询或申请权限，应用原有前台检查继续运行。

这里展示的是当前客户端的缓存，与ESP32自主天气缓存分别管理。自主运行状态须进入「首次配置 / 自主更新」读取，不能用手机缓存时间推断设备自主天气刚更新。

最近连接、发送回执和失败标记是本次运行的观测，不作为跨重启历史记录。持久化的天气和行情缓存仍可查看。设备回执只能说明软件保存/发送情况，不能代替实屏光学观察。诊断不上传个人配置、密钥或日志。


## 长时间运行与失联诊断（2026-10-29 固件）

固件在掉线15秒后尝试重连，后续间隔为30秒、60秒，之后保持60秒；每第4次尝试重新启动Wi-Fi驱动，不重启ESP32、不清除NVS、不自动全刷。配网、上传和天气TLS工作期间暂停恢复动作。重新取得IP后重建HTTP监听和mDNS公告，客户端仍须核验固定设备身份。

屏幕BUSY持续60秒不释放时，锁存显示故障并退出等待。已发生的局部显示无法保证成功，因此不确认显示基准或发送成功回执；在用户明确应用布局之前暂停自主刷屏。普通网络恢复不改变控制端、画面或基准。

`GET /api/local/health` 为只读接口，不返回待办、SSID、密码或密钥。包括固件修订、运行时长、IP/RSSI、掉线次数与最后原因码、重连/驱动重启次数、空闲/历史最低/最大连续内存、显示超时及基准状态。失联时无法请求该接口，应在恢复后读取，并结合串口故障记录判断；没有现场记录不能只凭断线现象确认原因。

这是异常路径修复及有限实机验证，不代表已经通过数天长期稳定性或所有路由器兼容测试。屏幕与供电硬件异常仍需排查。
