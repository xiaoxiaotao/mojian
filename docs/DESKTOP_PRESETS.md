# 桌面方案

Mac 0.4.1 / Android 0.7.1 新增六套用途组合，复用已有排版和信息卡片。

| 方案 | 组合 | 使用前准备 |
| --- | --- | --- |
| 轻办公 | 大待办、盆栽、本周进度与重要日期 | 自行添加重要日期，盆栽来自真实完成记录 |
| 会议日 | 日程排版、下一场日程、办公状态 | 授权并选择系统日历，手动设置状态 |
| 出门前 | 待办、驾车通勤、出门天气 | 高德Key、起终点和联网天气 |
| 深度工作 | 大清单、本周进度、状态牌 | 不自动启动计时、改变状态或系统免打扰 |
| 日常小习惯 | 待办、习惯、每日一句 | 自行添加习惯并手动打卡 |
| 下班慢生活 | 农历、月历、四时插画 | 现有工作清单保留；节气数据仍遵循年份支持范围 |

Mac：布局空间上方选择方案。Android：我的→桌面方案。没有设备也可预览；显示当前本机数据，未配置的模块显示提示，不填充假数据。预览不修改配置、不联网申请授权、不调用模型。Android可保存至收藏；两端沿用已有模板导入、导出与应用入口。

确认应用时全刷一次，日常内容继续局刷。只替换布局、比例与卡片类型；原待办、地址、Key、小纸条、周目标、习惯、重要日和手动状态保持。生活日历在Mac遵循已有手动作息覆盖规则，下一作息边界可恢复，不修改作息设置。

方案源为`config/desk-presets.json`；修改后运行`python3 tools/generate_preset_catalog.py`，生成的Swift和Java文件均提交。`--check`验证生成文件一致性；原生隔离检查覆盖导入字段边界、预览不修改数据及无数据时渲染。
