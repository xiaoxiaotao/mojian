# 墨间 Android

原生 Android 客户端，当前 0.7.7，Android 8.0+。手机与 ESP32 独立使用，无需运行 Mac。蓝牙发现设备地址，内容经同一局域网 Wi-Fi 传输，设备直连不需要口令。

## 已实现

- 工作台：最多八条待办，编辑、改期、三项置顶、完成后消失、删除、撤销及本机完成/删除记录恢复。
- 布局：六套预设、自定义待办比例，明确应用时全刷一次；日常待办局刷保留天气、行情与固定红色。
- 信息：城市搜索、苏州默认天气、五支自选股票、缓存及失败保留、卡片/小纸条/周目标配置。
- 设备：BLE发现、手动地址、读取设备最新内容、五秒检查、前台按分钟局刷时钟、离线保留本机编辑；清单冲突先让用户选择来源。

历史文字保存在本机；可选共享服务可以同步按ID去重的完成统计、习惯和重要日期，所有偏好及实时服务并未完整双向同步。手机接管布局使用 `.phone` 后缀，Mac 需明确应用布局后接管。

## 助手与提醒（0.4.0）

- 独立的原生 DeepSeek 工具循环，可查询时间、清单、天气、自选行情和启用的偏好；支持停止、两分钟超时、最多六轮推理及十二次工具调用。不是官方 Android Harness SDK。
- 待办新增/编辑/置顶/完成/删除、布局切换、偏好保存与提醒设置先生成确认卡片。确认前无业务写入；确认时校验最新事项，过期卡片与重复新增会被拒绝。确认布局明确全刷一次，其余任务仍走原有局刷队列。
- 偏好可手动添加、编辑、启停、删除和恢复。只向模型提供启用且未删除的条目，不从聊天自动偷偷保存。
- 本地待办提醒默认关闭。开启后安排截止前十分钟及到期通知；免打扰默认北京时间22:00至次日08:00，到期提醒顺延，最多补发最近24小时内的到期提醒。完成/删除取消计划，改期使用新的去重键。通知入队记录不等同于用户实际看到。
- 通知需要系统授权；Android 12+ 未允许精确闹钟时使用系统非精确闹钟，界面显示状态。手机厂商省电、强制停止及系统权限可能使通知延迟或停止。仅手机已保存的清单参与本地提醒，离线期间无法知道其他客户端的新修改。
- 对话/确认卡片/偏好使用本机原子文件保存，执行中断会标记待核对，避免自动重放。Key 在 Android Keystore 中加密保存，不写进源码或 APK。设置页可替换/移除；模型使用官方 HTTPS 端点。

入口：底部「助手」提出需求；「我的 → DeepSeek 连接」配置 Key；「我的 → 本地提醒」开启通知及查看精确闹钟权限。消息、必要任务信息与启用偏好会发送给 DeepSeek。手机的密钥、对话、偏好和提醒设置不会自动同步到 Mac。

## 能力边界

已提供只读系统日历、高德通勤、场景与生活画报、可选共享服务，详见下文。完整设置和会话并非跨端双向同步；不宣称与 Mac 全功能对等。纯蓝牙内容传输未实现，蓝牙用于发现与配网。

## 构建

从项目根运行 `sh tools/build_android.sh`，环境要求见 [开发指南](../docs/DEVELOPMENT.md)。输出 `dist/desk-todo-debug.apk`。原来已安装的 0.2.x 可覆盖升级。

## 0.4.1 界面与交互

- 主导航收敛为「工作台 / 助手 / 我的」。设备、布局、显示内容、偏好、提醒和模型连接集中在「我的」，子页面支持返回来源及旋转恢复返回栈。
- 工作台突出新增和完成：底部固定新增入口，点击事项正文编辑，更多菜单放置置顶/删除；移除后提供8秒撤销，历史与画面预览默认折叠。
- 助手输入区独立于消息滚动区，固定在底部；查询进度只更新文本，不重建页面。工具过程可展开，确认卡片区分主要/次要动作，日期以北京时间展示。
- 统一深绿/暖白、文字层级、表单常驻标签与48dp操作目标；窄屏及1.3倍字体下做原生布局约束检查。布局提供示意选择卡，只有确认应用后才保存并发送。天气/股票/卡片分别进入子页面，行情保存后直接获取与局部同步。
- 后台设备检查/同步结束时，若正在输入则只更新状态，避免抢焦点。输入法与系统安全区使用窗口适配；需继续在真机验收键盘弹出、收起和手势返回。

```sh
adb shell am instrument -w com.desktodo.app/com.desktodo.app.UiChecks
```

`UiChecks` 在未挂载到屏幕的原生 View 树中使用测试清单，检查360dp宽、默认及1.3倍字体的主要页面、动作区、点击目标、表单入口和布局配置不被渲染改写；导出三页原生示例图，不控制用户界面或修改实际清单。328项布局断言通过，助手及原有渲染/同步检查通过。该检查不代替键盘/返回/真实屏幕的人工验收。完整设计取舍见 [Android界面说明](../docs/ANDROID_UI.md)。


## 0.5.0 场景与卡片

入口：「我的 → 选择场景 / 搭配卡片」；「工作台 → 专注一小会儿」。

- 工作桌面、专注桌面、生活画报三套场景；800×480预览与上屏共用同一渲染器，点击可放大拖动。选择预览不更改配置，确认应用后全刷一次，保留当前清单。未连接也可预览。
- 六类卡片：生长小盆栽、本周进度、重要日倒计时、出门提示、办公状态、小纸条。右侧卡片独立清底重绘，保留任务/天气/行情和固定红色；老基准在明确应用场景或保存卡片前不会静默迁移。
- 统计基于本机完成记录，撤销扣回、删除不计入，周一归零；独立保存56天内最多4096条只含ID/完成时间的统计记录，避免历史列表100条裁剪导致统计下降。与Mac历史不自动合并。
- 最多六个重要日期，按北京时间自然日计算；真实专注支持5至90分钟、暂停/继续/结束、关联当前事项。通知由AlarmManager安排，未允许精确闹钟时可能延迟；系统通知权限仍由用户开启。暂停、停止和重复回执不会重复提醒。
- 生活画报使用系统ICU农历、项目已有2026节气表和程序绘制的季节山景；其他年份不猜节气。无生图服务依赖。
- 手机前台按分钟更新画面，后台到期通知不等于后台持续刷新屏幕；回到前台会按真实截止时间校正。
- 配置修改与任务修改共用版本回执保护，视觉待同步状态独立保存。若另一个控制端改了配置，停止自动覆盖；重新读取后可核对并手动同步。

新增隔离检查：

```sh

```

验证统计边界/撤销/成长、日期/农历、专注暂停继续及通知资格、场景渲染、保留带和卡片逐像素清除/区域保持、配置冲突与丢回执识别。Debug测试不写用户清单、实屏或真实通知。UiChecks覆盖新增页面及放大字体，482项布局断言通过。系统闹钟实际到达、真实键盘和实屏残影仍需人工验收。

## Android 0.6.0：日常与扩展

「我的」新增手机日历（只读、可选择来源）、高德驾车通勤查询、最多三个习惯打卡、最多十二个场景收藏与JSON模板导入导出。重要日期上限统一为12个。新增日程、通勤、习惯、每日灵感和数据插件卡片，仍按原区域清底局刷。

可选「共享与扩展」连接自托管服务，按ID交换完成记录、习惯与日期；默认手动，也可显式开启前台每分钟自动共享。可浏览/发布模板和纯数据插件、审核留言；不启用公共云。API Key分作用域在Keystore加密，模型上下文排除新增日历、习惯、收藏和共享凭据。完整协议、部署方式与限制见 [第三轮说明](../docs/ROUND3.md)。
