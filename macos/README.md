# 墨间 Mac 客户端

原生SwiftUI客户主线，当前0.2.5。支持Apple Silicon、macOS14+。构建及独立克隆步骤见[开发指南](../docs/DEVELOPMENT.md)。

## 使用

- 工作台：新增/编辑/完成/撤销待办，最多8条未完成、3条置顶；完成记录可恢复。
- 布局空间：六套预设与自定义。应用新布局需全刷一次，日常内容只局刷。
- 作息与日历：手动/自动工作切换、下班万年历、系统通知。
- 智能助理：官方DeepSeek Harness，固定查询工具、待确认写操作、偏好与通勤提醒；可停止，宿主120秒超时。
- 设备与设置：BLE发现、Wi-Fi局域网连接、Key、天气与股票、通勤。
- 信息卡片：配置两张卡；重要日自然日倒计时、周目标、系统日程、逐小时出门天气、小纸条。

日历须主动授权并选择，内容不自动发给DeepSeek。提醒需Mac应用运行且系统允许通知；错过24小时内可补，已有提交记录去重，下班模式不推工作提醒。

## 本地数据

`~/Library/Application Support/MoJian/`存储状态、提醒去重与Agent会话。Key存钥匙串，空白字段不会删除已有Key。开发签名更换后可能需要重新授权；不要通过改变钥匙串权限绕过系统提示。

## 测试

从仓库根执行`sh tools/test.sh`。CLI包含`--self-test`、`--reliability-test`、`--information-test <输出目录>`、`--task-management-test`。不需要真实Key；示例输出不代表用户生产内容。
